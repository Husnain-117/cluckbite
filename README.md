# Cluck Bite - Restaurant Ordering System

A modern restaurant ordering system built with React, TypeScript, and Tailwind CSS.

## Features

- 🍗 Browse menu with categories
- 🛒 Shopping cart functionality
- 📦 Order placement (delivery & collection)
- 📊 Manager dashboard for order management
- 👤 Admin dashboard for analytics & settings
- 🔔 Real-time notifications

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Supabase (Database, Auth, Edge Functions)
- **Build Tool**: Vite

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Environment Variables

For deployment, set these environment variables:

- `VITE_SUPABASE_URL` - Your Supabase project URL
- `VITE_SUPABASE_PUBLISHABLE_KEY` - Your Supabase anon key
